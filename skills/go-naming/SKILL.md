# Go Naming

- **Packages:** short, lowercase, one word, no underscores or `mixedCaps` (`order`, not `order_service` or `orderService`). Avoid `util`, `common`, `helpers`.
- **Files:** lowercase, words separated by `_` (`order_repository.go`, `order_test.go`).
- **Identifiers:** `MixedCaps` for exported, `mixedCaps` for unexported. No `snake_case`, no `SCREAMING_CASE` constants.
- **Acronyms** keep one case: `ID`, `URL`, `HTTP` (`userID`, `ParseURL`, `HTTPClient`), not `UserId` or `HttpClient`.
- **No stutter:** the package name is part of the name. `product.Controller`, `product.Usecase`, `product.CreateInput`, not `product.ProductController`.
- **Getters** have no `Get` prefix: `u.Name()`, setter `u.SetName()`.
- **Interfaces** are named by what they are (`usecase`, `productRepository`, `paymentGateway`), not by single-action roles (`productCreator`, `productGetter`).
- **Receivers:** short (one or two letters), the same for every method of a type, never `this` or `self`.
- **Errors:** sentinel values `ErrXxx`, error types `XxxError`.
- **Names that hide several concerns:** if a type's name needs "And", "Manager" or similar catch-all words, it likely mixes concerns. Split it (see single responsibility in `go-oop`).
- **Length follows scope:** short names for small scopes (`i`, `u`), descriptive names for package-level and exported identifiers.

## Project exceptions

- **`app_context`**, the package generated by go-train DI, keeps its framework-given name. Import it as `appctx`.
- **Same-named packages across layers** (`usecases/product`, `controller/product`): alias the other layer's import with a layer suffix, e.g. `productusecase`.
